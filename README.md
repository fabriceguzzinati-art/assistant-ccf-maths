# 🎓 Assistant Pédagogique IA - CCF Maths

Cet outil permet aux enseignants de mathématiques (particulièrement en Bac Pro) de générer des sujets de CCF conformes au BO, des exercices différenciés et d'aider à la correction de copies manuscrites via l'IA Gemini.

## 🚀 Fonctionnalités
- **Génération de CCF :** Sujets complets avec problématique, compétences BO et grille d'évaluation.
- **Export Word (.docx) :** Mise en page officielle prête à imprimer.
- **Correction IA :** Analyse de photos de copies d'élèves avec barème personnalisable.

## 🛠️ Installation (Local)
Si vous souhaitez le faire tourner sur votre PC :
1. Installez Python 3.10+
2. `pip install -r requirements.txt`
3. `streamlit run app.py`

## 🔐 Sécurité & RGPD
Le code source est déposé sur **La Forge Éducation**. L'utilisation nécessite une clé API Google Gemini (version gratuite ou pro). Aucune donnée personnelle d'élève n'est stockée de façon permanente sur les serveurs.
